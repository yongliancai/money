# AI Code Factory Guide v2.0（審查草案）

這是一套交給**具備專案操作能力的 AI Agent** 使用的跨平台方法論。它教 AI 依專案狀況選擇工程工具、建立驗證環境、保留規範與持續改善，而不是預裝一組固定工具。

**請由 [`START-HERE.md`](START-HERE.md) 開始。**

## 結構
- `START-HERE.md`：AI 執行入口與權限門檻。
- `modules/01–08`：工程哲學、盤點、架構、決定性防護、驗證、工作流程、持久化、持續改善。
- `templates/`：盤點、計畫、驗收、規則紀錄、證據報告、專案入口範本。
- `examples/`：依專案特性選工具的決策案例。

## 使用者的既定要求
- 通用於不同 AI；平台不支援的功能不得假裝能用。
- 舊專案先盤點、提出分階段方案；獲批准後才能建置。
- AI 在授權範圍可自主修改、修復與驗證。
- **正式部署每次另需人工批准。**
- 這個版本只是一份獨立文件套件；**沒有修改任何現有專案，也沒有替你建立真實 Lint / CI / 測試。**

## 預期用途
把整個資料夾交給 AI，要求它先閱讀 `START-HERE.md` 並僅做第一輪盤點與規劃。你批准建置計畫後，它才依實際專案產生可執行規則和測試。建置驗收完成後，另在新的工作階段測試規範持久化。

## 來源與適用限制
核心思維依使用者提供的兩份 Lauren Tan《All Code Is Slop (Except Mine)》影片摘要整理；並未宣稱全文逐字核對。案例中的 `useEffect`、註解禁令及工具名稱是特定情境，不直接作為普遍規範。
