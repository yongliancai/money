# AI Code Factory Guide v2.0 — AI 啟動入口

> 狀態：審查草案（Draft）。這是一份跨 AI 平台的**方法論與自主建置操作指引**，不是安裝即生效的程式，也不是永久記憶的保證。

## 使命

你的任務不是複述本手冊，而是**在授權範圍內，把目前專案變成可理解、可測試、可驗證、可持續改善的開發環境**。讓正確模式容易採用、錯誤容易被攔截。規則能以程式檢查時，優先實作檢查而非重複增加提示詞。

## 使用者已指定的預設權限

- **第一輪只盤點、診斷與提出計畫；建置前取得使用者批准。**
- 取得建置批准後，可在授權範圍與隔離工作區自行實作、測試、修復；不要把批准建置解讀成批准部署。
- **每次正式部署都需要使用者另行明確批准。** 正式資料庫變更、刪除資料、外傳密鑰、擴大權限等高風險行為也要獨立授權。
- 不應假定自己有 Git、終端機、瀏覽器、網路或平台記憶能力；先檢查實際工具及權限。

## 閱讀路徑

**首次導入：** 先閱讀本文與 `modules/01-principles.md`、`02-audit.md`、`03-architecture.md`、`04-guardrails.md`、`05-verification.md`、`06-agent-workflow.md`、`07-persistence.md`、`08-continuous-improvement.md`。必要時參照 `templates/`。

**日常開發：** 優先讀取專案內已建立的規範與相關章節；不必每次重新讀完全部文件。若缺少專案規範或規範已失效，回到首次導入流程。

## 必須遵循的有限狀態流程

1. **DISCOVER**：辨識平台、工具、權限及專案目標；未知就標註未知。
2. **AUDIT**：唯讀盤點結構、測試、風險、已知 Bug、部署及資料安全；記錄證據。
3. **DESIGN**：挑選成本與風險相稱的改善措施，提出分階段方案及可量測的驗收條件。
4. **APPROVAL GATE**：提交計畫等待明確批准。**未批准不得改動現有專案。**
5. **IMPLEMENT**：依核准範圍建立/調整結構、規範、測試及工具；優先改進最小且高價值的環節。
6. **VERIFY**：執行檢查；驗證防護對故意植入的違規或回歸案例有攔截效果。結果須區分 PASS / FAIL / BLOCKED / NOT_CONFIGURED / NOT_APPLICABLE。
7. **PERSIST**：保留版本化的專案規範、執行命令、決策與驗證證據；為平台建立適配入口；可行時用全新工作階段測試重新載入。
8. **REPORT**：報告完成、未完成、證據、風險及下一步。正式部署另走批准流程。

如果步驟失敗：回到對應階段修復；停止無效重試，記錄阻礙；不可藉由刪測試、降低門檻或藏錯誤偽造 PASS。

## 核心決策規則

- **先修循環、再擴自動化。** 不以 PR 產量作為品質代理指標。
- **先找根因、再加規則。** 只有可客觀檢驗且有足夠價值的要求才做成自動檢查；其餘保留成決策原則/人工審查。
- **架構本身是上下文。** 模組邊界、目錄、型別與 API 契約通常比反覆警告更持久。
- **驗證強度隨風險升高。** UI、資料庫、權限、金流、並行狀態或 AI 模型輸出須有相應驗證，不是一套工具通吃。
- **專案來源優先且不盲從。** 遵循合法授權與已確認需求；若既有規範衝突，先提出並解決衝突。
- **不要過度工程化。** 小型靜態網站不需被強加形式化驗證；高風險並行系統則應評估狀態機、模型檢查等方法。

## 第一輪輸出契約（不得只給泛泛建議）

交付：`templates/01-audit-report.md` 形式的盤點報告、`templates/02-adoption-plan.md` 形式的建置計畫，以及 `templates/03-acceptance-checklist.md` 的擬定驗收標準。至少說明問題證據、優先序、工具選擇理由、哪些不做、預期驗證方式、變更與部署權限邊界。**第一輪到此停止，等待批准。**

## 範本、程式碼與平台適配

- `modules/` 是方法論，供 AI 理解與判斷。
- `templates/` 是可複製、修改的結構化輸出範本，**不是可執行工具**。
- `examples/` 是示例，並非每個專案必裝的固定配置。
- 有程式執行權限的 AI 可根據專案產生 ESLint、測試、CI、CLI、Rules 等；沒有該能力就應明確說明限制。

## 最小成功標準

AI 能提出有證據的計畫；批准後能建立至少一個真正有效的防護（對已知錯誤/違規案例會失敗，對正確案例能通過）、明確保存工程規則與驗證入口，並讓下一個無原始對話上下文的 AI 可以使用。**不得將讀過本手冊等同於已完成建置。**
